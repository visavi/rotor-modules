# Changelog

## 1.2.0
- API записи: сама запись теперь в `data`, комментарии — в `comments` со своей пагинацией
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0

## 1.1.0
- Добавлен список новостей: `GET /api/news`
- Добавлен API раздела: `GET /api/news/{id}` отдаёт новость с комментариями постранично, токен необязателен — гость читает, авторизованный получает ещё и свой голос

## 1.0.5
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.4
- `created_at` переведён с int-timestamp на `datetime` (миграция-конверсия через PHP/Carbon, сохраняет исторический DST), добавлено `updated_at`
- Модель на авто-timestamps Eloquent (`$timestamps`), `created_at`/`updated_at` кастуются в Carbon
- Чтения переведены с int на Carbon: RSS `pubDate`, sitemap `lastmod`, статистика «за день»
- Требуется ядро 14.1.0

## 1.0.3
- Текст для RSS/API вынесен в метод модели `getShareText()` (`absolutizeUrls(renderHtml())`); rss-шаблон переведён на него
- RSS enclosure: `getMedia()` → `getDetachedMedia()` (только не привязанные к тексту файлы)

## 1.0.2
- Аудиоплеер растянут на всю ширину (`w-100` вместо `img-fluid`) в админке, ленте, списке и просмотре новостей — пропадал в некоторых браузерах из-за css

## 1.0.1
- Рейтинг переведён на общий виджет голосования ядра (`app/_rating`)
- Единый стиль кнопок рейтинга в ленте, списке и просмотре новостей
- Требуется ядро 14.0.1
