# Changelog

## 1.0.2
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно

## 1.0.1
- Исправлен баг: подарок выдавался повторно — модуль не создавал запись в `surprise`, проверка `existSurprise` всегда была пустой. Теперь выдача фиксируется (user_id + year)
- Поле `surprise.created_at` переведено с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон)
- `$timestamps = false` заменён на `const UPDATED_AT = null` (updated_at-колонки нет, created_at заполняется авто)
- Требует ядро 14.1.0
