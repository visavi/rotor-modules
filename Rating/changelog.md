# Changelog

## Unreleased
- Строка об изменении репутации в FAQ регистрируется модулем через `Registry::faqAbility()`, перевод — в модуле
- Отказы (закрыто, не автор, нет записи и т.п.) отвечают кодом 403 или 404 вместо 200 с текстом ошибки — ajax и API видят ошибку по статусу
- Исправлено: значение голоса, отличное от «плюс», засчитывалось минусом в обход правила «минусовать можно только с положительной своей репутацией» — теперь принимаются только «плюс» и «минус»
- Ошибка «минусовать нельзя» показывается под выбором голоса, выбранный голос сохраняется после ошибки
- Требует ядро 14.9.0
- Подсветка поля с ошибкой в настройках — под ядро 14.9: ключи ошибок `sets.имя` вместо `sets[имя]`

## 1.1.0
- Вызовы `antimat()` убраны: с ядра 14.7.0 фильтр слов применяется при выводе кастом модели, в базе хранится оригинал
- Кнопки управления модулем в админке выводятся на языке пользователя, а не сайта: в `module.php` ключи перевода вместо `__()`
- Репутация в списке пользователей рисуется модулем (хук userCardStats), ядро её больше не выводит
- Репутация в анкете: плитка с итогом в шапке и блок с полосой соотношения, долей плюсов и кнопками голосования
- Требуется ядро с хуками userStats и userSections
- Репутация выводится полем анкеты, в одном списке с остальными полями
- Страница настроек показывает боковую панель настроек сайта — переключение между разделами без возврата в админку
- Требуется ядро 14.7.0

## 1.0.3
- Удаление записи из истории рейтинга переведено на ядровой `data-ajax`, свой JS-обработчик больше не нужен
- Ответ на удаление содержит текст сообщения (раньше его подставлял клиент)

## 1.0.2
- Добавлены тесты (`Tests/Feature/RatingTest.php`): голосование, лимит в три месяца, история, удаление админом, чистка при удалении пользователя
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0

## 1.0.1
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.0

- Репутация пользователей вынесена из ядра в модуль
