# Changelog

## 1.1.2
- Индекс перед подменой колонок дропается, только если он есть (`1091 Can't DROP`)

## 1.1.1
- Кнопка жалобы переведена на ядровой `data-ajax`, свой JS-обработчик больше не нужен

## 1.1.0
- API гостевой: `GET /api/guestbook`, `POST /api/guestbook`, `PATCH /api/guestbook/{id}`
- Гость пишет по API так же, как на сайте: с капчей (`GET /api/captcha`) и без ссылок в тексте, при `guest_moderation` сообщение ждёт проверки
- Медиа принимается и в теле запроса (`files[]`), и предзагрузкой через `POST /api/files`
- Лимиты текста публикуются в `/api/config` секцией `guestbook`
- Счётчик раздела приходит в `/api/stats`
- Импорты переведены с `App\Classes` на `App\Support`
- Требует ядро 14.3.0
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён

## 1.0.4
- Имя гостя запоминается в cookie `guest_name` (год) и подставляется в форму при следующем заходе
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.3
- Каталог тестов переименован `tests` → `Tests`
- Требует ядро 14.1.0

## 1.0.2
- Поля `created_at`/`updated_at` переведены с int (unix-таймстамп) на `DATETIME` (миграция с исторически-корректной конверсией таймзон)
- Включены стандартные авто-таймстампы Eloquent (`created_at`/`updated_at` проставляются автоматически); `updated_at` в выводе показывается только при правке (`edit_user_id`)
- Требует ядро 14.0.3

## 1.0.1
- Кнопки действий (ответить, цитировать, жалоба, правка) переведены на единый круглый стиль ядра (`js-actions`)

## 1.0.0
- Первый релиз
