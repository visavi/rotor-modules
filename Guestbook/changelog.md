## 1.2.0
- API: файлы, загруженные заранее, идут перед файлами из запроса — раньше вложения перемешивались
- Вложения — файлы, а не только медиа: можно прикрепить pdf, архивы и всё из списка допустимых расширений файлов. Раньше форма предлагала этот список, а сервер принимал только картинки и видео и отвечал «Недопустимое расширение файла!»
- API: гости не могут прикладывать файлы — как и на сайте. Файл гостя открыт по ссылке ещё до модерации и обходит запрет ссылок в тексте
- Форма сообщения стоит над записями: новые записи идут сверху, писать можно не пролистывая ленту. Кнопка «Написать» в шапке убрана — она только прокручивала к форме
- Форма над записями свёрнута в одно поле: панель редактора, файлы, имя гостя и капча появляются при первом клике в поле. После ошибки или с прикреплёнными файлами форма сразу открыта. У гостя имя перенесено под сообщение
- Вложения в формах выводятся в порядке, заданном перетаскиванием миниатюр, а не по дате загрузки
- Требуется ядро 14.8.0

## 1.1.5
- Вызовы `antimat()` убраны: с ядра 14.7.0 фильтр слов применяется при выводе кастом модели, в базе хранится оригинал
- Колонка `reply` помечена `HtmlCast::class . ':nullable'`: с ядра 14.7.0 каст по умолчанию пишет null пустой строкой, а колонка допускает NULL
- Название раздела (поиск, лента, жалобы) и кнопки управления в админке выводятся на языке пользователя, а не сайта: в `module.php` ключи перевода вместо `__()`
- Страница настроек показывает боковую панель настроек сайта — переключение между разделами без возврата в админку
- Требуется ядро 14.7.0
- Переключатели в настройках вместо галочек

## 1.1.0
- API гостевой: `GET /api/guestbook`, `POST /api/guestbook`, `PATCH /api/guestbook/{id}`
- Гость пишет по API так же, как на сайте: с капчей (`GET /api/captcha`) и без ссылок в тексте, при `guest_moderation` сообщение ждёт проверки
- Медиа принимается и в теле запроса (`files[]`), и предзагрузкой через `POST /api/files`
- Лимиты текста публикуются в `/api/config` секцией `guestbook`
- Счётчик раздела приходит в `/api/stats`
- Импорты переведены с `App\Classes` на `App\Support`
- Требует ядро 14.3.0
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён
