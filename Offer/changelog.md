# Changelog

## 1.2.0
- API записи: сама запись теперь в `data`, комментарии — в `comments` со своей пагинацией
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- API: создание и правка записи (`POST /api/offers`, `PATCH /api/offers/{id}`)

## 1.1.0
- Добавлен список записей: `GET /api/offers?type=offer|issue` с сортировкой сайта
- Добавлен API раздела: `GET /api/offers/{id}` отдаёт запись с комментариями постранично, токен необязателен — гость читает, авторизованный получает ещё и свой голос
- Добавлена загрузка картинок и видео к предложениям и проблемам — скриншот можно приложить к записи, а не описывать словами
- Медиа выводятся галереей в ленте, на странице записи и в админке, как в объявлениях; вставленные в текст картинки в галерею не дублируются
- Файлы записи удаляются вместе с ней
- Лента подгружает файлы вместе с записью, поэтому `/api/feed` отдаёт медиа предложений без лишних запросов

## 1.0.4
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`
- В `delete()` общий редирект вынесен в переменную — URL одинаков для обеих веток

## 1.0.3
- Поля дат (`offers.created_at`/`updated_at`) переведены с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон, пересоздание индекса `created_at`)
- `$timestamps = false` заменён на `const UPDATED_AT = null`: created_at заполняется авто, а updated_at (время правки/официального ответа) остаётся ручным — чтобы инкременты `count_comments`/`rating` не сбивали дату ответа
- Сравнения/запись дат переведены на Carbon/`now()`, убран ручной `created_at => SITETIME`
- Требует ядро 14.1.0
