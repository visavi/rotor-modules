## 1.0.0
- Первый релиз: почтовая рассылка вынесена из ядра — напоминание о непрочитанных сообщениях и поздравление с днём рождения, отписка по ссылке из письма
- Настройки «Почта и рассылка» переехали из настроек сайта в настройки модуля, значения сохраняются
- Галочка «Получать информационные письма» — в настройках пользователя, только при включённом модуле. Повторное сохранение настроек больше не меняет ключ отписки: ссылки из уже отправленных писем работают
- API-клиент, не приславший `subscribe`, подписку не сбрасывает
