# Changelog

## 1.0.10
- Laravel-документация обновлена до ветки `13.x`, `docs:sync` по умолчанию тянет её же (новые разделы: AI, AI SDK, Boost, MCP, Head, Images, Search)
- Поиск по документации переехал с `/docs/search` на `/docs/find` — в Laravel 13 появилась страница `search`, и роут поиска её перекрывал
- Заработали переходы по якорям внутри страниц (`#web-servers` и прочие): якоря `<a name>` из исходников больше не теряются при вырезании html

## 1.0.9
- Сборка ресурсов: исходники js и css переехали из `public/assets` в `resources/js` и `resources/css`, обновлены алиасы и список точек входа
- Сборка ресурсов: описан общий Bootstrap (`resources/css/bootstrap.scss`), настройка тем через CSS-переменные и список того, что тема получает от ядра
- Шаблоны: исправлено имя настройки активной темы — `themes`, а не `theme`
- Шаблоны: создание темы описано в двух вариантах — со сборкой и без неё (пример `resources/views/themes/simple`), добавлен перечень обязательных секций layout

## 1.0.8
- Документация: создание и правка записей раздела через API
- Добавлены тесты (`Tests/Feature/DocsTest.php`): вывод страниц, поиск, соответствие навигации файлам документации

## 1.0.7
- Документация: порядок обновления между мажорами (мажор — только с последней версии предыдущего мажора) и предупреждение о модулях под старый мажор
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0

## 1.0.6
- Документация: комментарии и вложения в API — общие ручки ядра (`POST /api/comments`, `POST /api/files`), модулю свои писать не нужно
- Версионирование: классы `app/Support` (бывшая `app/Classes`) объявлены публичным API, `app/Services` — внутренности ядра; описан мост старых имён до 15.0

## 1.0.5
- Страница `/rotor/releases` показывает все релизы с пагинацией (по 10 на страницу), а не только последние 10; бейдж «последний» — только у первого релиза первой страницы
- Требует ядро с per_page=100 в `GithubService::getLatestReleases`

## 1.0.4
- Переход на datetime, минимальная версия движка 14.1.0
- Новая страница «Версионирование»: semver ядра, публичный API, семантика requires, чек-лист автора модуля

## 1.0.3
- Документация по `module:sync` (заменил `module:link`): синхронизирует симлинки, перепубликует файлы секции `publish`, сбрасывает кеш модулей
- Добавлена документация секции `publish` в module.php — публикация файлов модуля в произвольные директории движка
- Обновлены команды/деплой/обновление (`rotor-commands.md`, `rotor-deploy.md`, `rotor-upgrade.md`) под `module:sync`
- Переименована Lite-сборка релиза в Upgrade-сборку (`download_lite` → `download_upgrade`, иконка и текст в releases.blade.php)
- Иконка модуля в каталоге `/rotor/modules` заменена на `fa-cube`, карточка модуля не ломается на длинных названиях
- Исправлен перенос кнопок скачивания на мобильных в карточке релиза

## 1.0.2
- Добавлен публичный каталог модулей `/rotor/modules` — список из активных реестров (`module_registries`) с поиском и сортировкой, без состояния установки; показывает все версии модуля и ссылки на скачивание. Агрегация целиком в модуле (без правок ядра), без фильтра по версии сайта
- Страница релизов: добавлена кнопка скачивания Upgrade-сборки (без `vendor`) рядом с полной, когда ассет присутствует
- Счётчик загрузок суммируется по всем ассетам релиза
- Улучшена адаптивность страницы релизов на мобильных (кнопки скачивания в ряд, ссылка на GitHub и счётчик на всю ширину, компактнее карточки)
