# Своя главная

Главную страницу сайта можно собрать тремя способами — от «ничего не делать»
до «написать самому».

| Способ | Что нужно уметь | Когда подходит |
|---|---|---|
| Лента | ничего | по умолчанию: свежие записи всех разделов |
| Модуль главной | ничего | готовая раскладка или конструктор из блоков |
| Свой шаблон `index` | Blade и немного PHP | полный контроль над разметкой |

## Лента и модули

По умолчанию на главной лента. Модули добавляют свои варианты главной: выбор —
в «Панель → Настройки → Основные настройки → Главная страница».

- **Classic** — классическая главная со списками разделов, календарём и статистикой.
- **HomeBuilder** (конструктор главной) — главная из блоков: текст, свежие записи
  разделов, HTML-код, свои шаблоны. Начать можно с готового набора, блоки двигаются
  перетаскиванием, код писать не нужно.

Если модуль выбранной главной выключить, на главной снова лента.

## Свой шаблон index

Главную рисует шаблон `resources/views/index.blade.php`. Его копия в
`resources/custom/views/index.blade.php` заменяет оригинал целиком — см.
«[Свои правки](/docs/rotor-custom)».

Проще всего сделать копию в редакторе файлов: «Панель → Редактор файлов →
Шаблоны», открыть `index.blade.php` и нажать «Сохранить в «Мои правки»». Оригинал
останется нетронутым, дальше правится копия.

Оригинал выглядит так:

```blade
@extends('layout')

@section('title', setting('logos'))

@section('content')
    @hook('advertIndexTop')

    @if ($homepage)
        {{ $homepage() }}
    @else
        <div id="feed-container">
            {{ $feed->getFeed() }}
        </div>
        <div id="feed-sentinel"></div>
    @endif

    @hook('advertIndexBottom')
@stop
```

- `$homepage` — главная модуля, выбранная в настройках, или `null`. Если главная
  целиком своя, ветку `@if` можно убрать.
- `$feed` — лента сайта, `$feed->getFeed()` выводит её первую страницу. В копиях,
  сделанных раньше, лента выводится через `(new FeedService())->getFeed()` — так
  тоже работает.
- Хуки `advertIndexTop` и `advertIndexBottom` выводят рекламу и вставки модулей —
  их лучше оставить.

### Записи разделов

Свои запросы к моделям модулей писать не нужно. `FeedService::getLatest()` отдаёт
свежие записи любых разделов, подключённых к ленте, и сам отсекает скрытые записи:
черновики, записи на модерации, разделы выключенных модулей.

```blade
@use('App\Services\FeedService')

@php($news = (new FeedService())->getLatest(['news'], 5))

<div class="section shadow mb-3">
    <div class="section-title">Новости</div>

    @foreach ($news as $post)
        <div class="mb-2">
            <a href="{{ $post->getViewUrl() }}">{{ $post->title }}</a>
            <small class="text-muted">{{ dateFixed($post->created_at) }}</small>
        </div>
    @endforeach
</div>
```

Первый аргумент — список разделов, второй — сколько записей. Разделы можно
смешивать: `getLatest(['news', 'articles'], 10)` вернёт свежие новости и статьи
вперемешку, новые первыми. Раздел выключенного модуля молча пропускается.

| Раздел | Ключ | Модуль |
|---|---|---|
| Новости | `news` | News |
| Темы форума | `topics` | Forum |
| Статьи | `articles` | Blog |
| Загрузки | `downs` | Load |
| Фото | `photos` | Photo |
| Объявления | `items` | Board |
| Предложения и проблемы | `offers` | Offer |
| Комментарии | `comments` | ядро |

В ответе — обычные модели разделов, поэтому доступны их поля и методы:

| Что | Как |
|---|---|
| Ссылка на запись | `$post->getViewUrl()` |
| Заголовок | `$post->title` (у комментария заголовка нет — `$post->relate?->title`) |
| Дата | `dateFixed($post->created_at)` |
| Автор | `$post->user->getProfile()`, аватар — `$post->user->getAvatarImage()` |
| Первая картинка | `$post->getOgImage()` — пустая строка, если картинок нет. У тем форума метода нет: файлы лежат в сообщениях |
| Комментарии | `$post->count_comments`, у темы форума — ответы `$post->count_posts`. У объявлений комментариев нет |

Картинки:

```blade
@foreach ((new FeedService())->getLatest(['photos'], 8) as $photo)
    @if ($image = $photo->getOgImage())
        <a href="{{ $photo->getViewUrl() }}"><img src="{{ $image }}" class="rounded" style="width: 100px" alt=""></a>
    @endif
@endforeach
```

Записи в виде карточек, как в ленте, рисует `render()`:

```blade
@php($feed = new FeedService())

@foreach ($feed->render($feed->getLatest(['news'], 3)) as $card)
    {!! $card !!}
@endforeach
```

Блок, который запрашивает записи на каждом открытии главной, можно закешировать.
Ключ с версией ленты сбрасывается сам, как только в разделах появляется новая запись:

```blade
@php($news = cache()->remember('home_news_' . cache()->get('feed_version', 0), 600, fn () => (new FeedService())->getLatest(['news'], 5)))
```

### Чем платить за свободу

- **Копия не обновляется вместе с ядром.** Если в новой версии поменяется
  оригинальный `index`, копия останется старой, и никто об этом не скажет. После
  обновления сравните её с оригиналом: редактор файлов показывает у копии ссылку
  «Оригинал файла».
- **Ошибка в шаблоне ломает главную.** Опечатка в Blade — это 500 на самой
  посещаемой странице. Проверяйте главную сразу после сохранения. Чтобы вернуть
  оригинал, достаточно удалить копию в «Мои правки».

Если нужна своя раскладка, но не хочется отвечать за весь шаблон, посмотрите
на конструктор главной: у него свои виды записей правятся как обычные Blade-файлы,
а ошибка в одном блоке не роняет страницу.
