# Changelog

## 1.1.0
- Вкладка «Превью картинок»: сколько превью каждого размера и сколько они занимают, очистка одной кнопкой; оригиналы не удаляются, превью создаются заново при показе. Если часть файлов удалить не удалось (например, нет прав), админ видит ошибку, а не «Кеш успешно очищен»
- Требуется ядро 14.9.0

## 1.0.2
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0

## 1.0.1
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно

## 1.0.0
- Первый релиз, вынесено из ядра
