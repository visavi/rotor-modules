# Changelog

## 1.3.0
- Счётчик загрузок в `/api/stats` отдаёт выборку: ядро само считает всего и за сутки, минимальная версия ядра — 14.4.0

## 1.2.0
- API записи: сама загрузка теперь в `data`, комментарии — в `comments` со своей пагинацией
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- API: создание загрузки и правка своей непроверенной загрузки
- Счётчик проверенных загрузок отдаётся в `/api/stats` (ключ `downs`)
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён
- Содержимое архива читается один раз: карта записей кешируется на файл, страницы просмотра больше не открывают zip на каждый запрос
- Перебор несуществующих номеров файлов в архиве отбивается по карте, не открывая архив — этим занимались боты
- Картинки из архива отдаются с ETag и сроком кеширования: повторный запрос закрывает браузер
- Добавлены тесты (`Tests/Feature/ZipViewTest.php`): список файлов, просмотр текста и картинки, кеш карты и его сброс
- Просмотр содержимого архивов закрыт для гостей: гость уводится на вход, ссылка «Просмотр архива» ему не показывается, `archive_url` в API приходит `null`

## 1.1.0
- Запись отдаёт свою категорию объектом (`category_id` и `category` с родителем), как тема форума отдаёт раздел
- Добавлены список загрузок `GET /api/downs` (фильтр `category_id`, только проверенные) и категории загрузок `GET /api/loads`
- Добавлен API раздела: `GET /api/downs/{id}` отдаёт загрузку с комментариями постранично, токен необязателен — гость читает, авторизованный получает ещё и свой голос
- Файлы дистрибутива приходят ссылкой на роут скачивания, а не прямым путём: иначе не считались бы загрузки и обходился бы запрет скачивания гостям
- Непроверенная загрузка отдаётся по API только автору и администрации, остальным 403

## 1.0.6
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.5
- Поля дат загрузок (`downs.created_at`/`updated_at`) переведены с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон, пересоздание индекса `created_at`)
- Включены авто-таймстампы вместо `$timestamps = false` (как в News/Blog): created_at/updated_at заполняются авто, убраны ручные `SITETIME`
- При публикации загрузки `created_at` намеренно сбрасывается на `now()` (всплывает как новая), `updated_at` проставляет авто-таймстамп
- Сравнения/форматирование дат переведены на Carbon/`now()` (`isNew`, sitemap, rss, статистика); категория `Load` дат не имеет — без изменений
- Требует ядро 14.1.0

## 1.0.4
- Текст для RSS/API вынесен в метод модели `getShareText()` (`absolutizeUrls(renderHtml())`); rss-шаблон переведён на него
