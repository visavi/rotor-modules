# Changelog

## 1.1.0
- API блокнота: `GET /api/notebook`, `PATCH /api/notebook` — заметка одна на пользователя, читает и правит её только владелец
- Исправлено: на свежей установке в таблице `notebooks` не создавалась колонка `updated_at` (её добавляла только миграция перевода дат), из-за чего заметка не сохранялась
- Импорты переведены с `App\Support` на `App\Support`
- Требует ядро 14.3.0
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён

## 1.0.2
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.1
- Поле `notebooks.created_at` переведено с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон)
- Добавлена колонка `updated_at`: раньше `created_at` сбрасывался на каждом сохранении (= время правки). Теперь `created_at` = создание, `updated_at` = последняя правка; «Последнее изменение» в шаблоне берёт `updated_at`
- Включены авто-таймстампы вместо `$timestamps = false` (created_at/updated_at заполняются авто), убран ручной `SITETIME`
- При обновлении старых записей `updated_at` = прежний `created_at` (истинная дата создания была потеряна — `created_at` хранил время правки)
- Требует ядро 14.1.0
