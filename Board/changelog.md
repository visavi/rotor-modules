# Changelog

## Unreleased
- Подсказки города берутся из объявлений и анкет пользователей: город из анкеты попадает в подсказки, если его вписали хотя бы двое. В новое объявление город подставляется из профиля
- Нормализация города (пробелы, заглавная буква) переехала в ядро — `App\Casts\PlaceCast`, свой `CityCast` удалён
- Телефон в объявлении, списке и ленте открывается по кнопке «Показать телефон»: номера нет в HTML, парсеры его не соберут. Запрос номера ограничен 20 в минуту
- API и лента API отдают телефон только запросам с токеном, гостю `phone: null`
- Поле «Город»: свободный ввод с подсказками из городов других объявлений, город в объявлении ведёт на список объявлений этого города. В API поле `city` и фильтр `?city=`
- Галочки мессенджеров к телефону: WhatsApp, Telegram, Viber открываются чатом по номеру, MAX только отмечается (ссылки по номеру у него нет). Показываются вместе с номером по кнопке. В настройках каждый мессенджер можно выключить
- Страница объявления: цена под текстом, телефон и «Связаться с продавцом» кнопками в ряд, сведения одной строкой. Просмотры видны и у объявлений без фото, срок размещения — только автору и админу
- Цена с пробелами между разрядами: 12 500 вместо 12500
- Чужое объявление не открывается в форме автора: раньше форма открывалась и падала на сохранении с «Вы не автор», админа теперь перенаправляет в админку
- Вложения в формах выводятся в порядке, заданном перетаскиванием миниатюр, а не по дате загрузки
- Дата объявления совпадает с его местом в списке: в ленте и поиске — дата подачи (продление не поднимает объявление в ленте), в разделе — дата продления, по которой идёт сортировка. На странице продлённого объявления видны обе даты: подачи и «Продлено»
- Требуется ядро 14.8.0

## 1.5.1
- Вызовы `antimat()` убраны: с ядра 14.7.0 фильтр слов применяется при выводе кастом модели, в базе хранится оригинал
- Заголовок объявления через `TextCast`: антимат действует и на него, раньше только через API
- Название раздела (поиск, лента, жалобы) и кнопки управления в админке выводятся на языке пользователя, а не сайта: в `module.php` ключи перевода вместо `__()`
- Страница настроек показывает боковую панель настроек сайта — переключение между разделами без возврата в админку
- Переключатели в настройках вместо галочек
- Миграция добавляет колонку `visits` в базы со старого движка: просмотр объявления падал с `1054 Unknown column 'visits'`

## 1.5.0
- Индекс перед подменой колонок снимается по реальному имени: базы со старого движка держат его без суффикса `_index`, дроп падал с `1091 Can't DROP`
- Категории переставляются перетаскиванием прямо на странице категорий, вместе с вложенными
- Страница категорий показывает вложенность любой глубины: раньше рисовалось два уровня
- Уровень категории задаётся горизонтальным движением мыши, как в админках Drupal и XenForo
- Счётчик категории складывает объявления всей ветки, а не только свои
- Правка и удаление — в одной строке списка и в одной строке формы правки
- Поле «Положение» убрано из формы правки категории: порядок задаётся перетаскиванием
- Категорию с подкатегориями можно сделать вложенной и через форму правки: запрет остался только на удаление непустой категории
- Кнопка возврата из админки на сайт помечена глазом, а не ключом — как в остальных модулях
- У счётчика категорий появилась подсказка «Объявления»
- Счётчик категории на публичной странице складывает всю ветку, в заголовке тоже

## 1.1.0
- Объявление отдаёт свою категорию объектом (`category_id` и `category` с родителем), как тема форума отдаёт раздел
- Добавлены список объявлений `GET /api/items` (фильтр `category_id`, без истёкших) и категории объявлений `GET /api/boards`

## 1.0.3
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`
- Смоук-тест обновлён под новый ключ флеша (`session('danger')` вместо `session('flash.danger')`)

## 1.0.2
- Поля `created_at`/`updated_at`/`expires_at` объявлений переведены с int (unix-таймстамп) на `DATETIME` (миграция с исторически-корректной конверсией таймзон)
- Сравнения и арифметика срока (`expires_at`) переведены на Carbon/`now()`; `$timestamps` оставлен выключенным — условная логика `updated_at` при перевыставлении сохранена
- Требует ядро 14.1.0
