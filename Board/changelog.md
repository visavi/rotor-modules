# Changelog

## 1.4.1
- Миграция дат не падает при повторном запуске: временные колонки создаются только при отсутствии (`1060 Duplicate column name`)
- Индекс перед подменой колонок дропается, только если он есть (`1091 Can't DROP`)

## 1.4.0
- og-теги (Open Graph) для объявления: описание, канонический адрес, картинка и тип `article`
- Точка вставки кнопок «Поделиться» — хук `share`
- Текст объявления с сайта проходит через антимат — через API фильтр работал, через форму нет

## 1.3.0
- Счётчик объявлений в `/api/stats` отдаёт выборку: ядро само считает всего и за сутки, минимальная версия ядра — 14.4.0

## 1.2.0
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- API: создание, правка, снятие с публикации и удаление объявления
- Счётчик действующих объявлений отдаётся в `/api/stats` (ключ `items`)
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён

## 1.1.0
- Объявление отдаёт свою категорию объектом (`category_id` и `category` с родителем), как тема форума отдаёт раздел
- Добавлены список объявлений `GET /api/items` (фильтр `category_id`, без истёкших) и категории объявлений `GET /api/boards`
- Добавлен API раздела: `GET /api/items/{id}` отдаёт объявление одной записью — комментариев и рейтинга у раздела нет, поэтому пагинации в ответе тоже нет
- Истёкшее объявление по API доступно автору, остальным авторизованным 403 — правило то же, что на сайте

## 1.0.3
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`
- Смоук-тест обновлён под новый ключ флеша (`session('danger')` вместо `session('flash.danger')`)

## 1.0.2
- Поля `created_at`/`updated_at`/`expires_at` объявлений переведены с int (unix-таймстамп) на `DATETIME` (миграция с исторически-корректной конверсией таймзон)
- Сравнения и арифметика срока (`expires_at`) переведены на Carbon/`now()`; `$timestamps` оставлен выключенным — условная логика `updated_at` при перевыставлении сохранена
- Требует ядро 14.1.0
