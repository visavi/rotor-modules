# Changelog

## 1.2.0
- Настройки провайдеров (ключи и секреты OAuth) доступны только владельцу сайта, как и остальные настройки
- Кнопки управления модулем в админке выводятся на языке пользователя, а не сайта: в `module.php` ключи перевода вместо `__()`
- Привязки аккаунтов показываются секцией на странице «Мои данные» (хук accountSections), ссылка из анкеты убрана
- Ссылка на привязанные аккаунты в анкете выводится строкой-компонентом

## 1.1.0
- Страница настроек показывает боковую панель настроек сайта — переключение между разделами без возврата в админку
- Настройка «Автоматически привязывать аккаунт по email» убрана: подтверждённый провайдером адрес привязывается к существующему аккаунту всегда
- Запись social_autolink_email удаляется из settings миграцией
- Адрес, введённый вручную, проходит подтверждение письмом, если сайт его требует: аккаунт заводится ожидающим и до перехода по ссылке дальше страницы подтверждения не пускает
- Переключатели в настройках вместо галочек

## 1.0.7
- Страница `/admin/socials` — список привязок с фильтром по провайдеру, счётчики привязок и активных за месяц
- Плитка привязок в админ-панели через хук `adminBlockAdmin`
- Колонка `socials.last_login_at` — время последнего входа через провайдера (`created_at` остаётся временем привязки)

## 1.0.6
- Виджет привязок соцсетей на главной админки

## 1.0.5
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0

## 1.0.4
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Уведомления о привязке/отвязке соцсети переведены на `redirect()->with()`

## 1.0.3
- Таймауты HTTP-запросов к OAuth-провайдерам (connect 5s / total 10s) — висящий провайдер больше не держит воркер 30 секунд
- Сетевой сбой (`ConnectionException`) при входе показывает сообщение об ошибке вместо страницы 500

## 1.0.2
- `socials.created_at` переведён с `TIMESTAMP` на `DATETIME` — единый тип дат во всём проекте (без проблемы 2038 и UTC-сдвига сессии). Модель `Social` уже на авто-`created_at` (`const UPDATED_AT = null`), типизирована константа
- Требует ядро 14.1.0

## 1.0.1
- Проверка чёрного списка при регистрации через соцсети: email и домен блокируют вход
- Blacklist-логин больше не блокирует, а перегенерируется
- Генерация логина использует полные 20 символов (было 16)
