# Changelog

## 1.2.0
- Поле логина получателя заменено на список с автодополнением (`bootstrap5-tags`, поиск через `/search-users`) — несуществующий логин ввести нельзя
- Подарок отправляется сразу нескольким получателям: поле `users[]`, лимит задается настройкой `max_users` (по умолчанию 10), деньги списываются за каждого, уведомление уходит каждому
- Итоговая сумма пересчитывается на лету при выборе получателей
- **Ломающее изменение API**: `POST /api/gifts/{id}/send` принимает `users` (массив логинов) вместо `user` (строка); неизвестный логин отменяет всю отправку
- Текст уведомления об отправке подарка вынесен из контроллера в шаблон уведомлений (`/admin/notices`, тип `gift_send`): миграция создает шаблон на языке, установленном на момент установки, откат миграций (удаление модуля) его удаляет
- Метки шаблона: `%login%` — отправитель, `%gift%` — картинка подарка, `%text%` — текст отправителя, `%page%` — ссылка на подарки получателя

## 1.1.0
- API подарков: `GET /api/gifts` — каталог, `GET /api/gifts/{login}` — подарки пользователя, `POST /api/gifts/{id}/send` — отправка
- Просроченные подарки в выдачу не попадают, как и в профиле на сайте
- Импорты переведены с `App\Support` на `App\Support`
- Требует ядро 14.3.0
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён

## 1.0.2
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.1
- Поля дат (`gifts.created_at`, `gifts_users.created_at`/`deleted_at`) переведены с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон)
- Включены авто-таймстампы вместо `$timestamps = false`: `const UPDATED_AT = null` (updated_at-колонки нет, created_at заполняется авто); `deleted_at` (срок действия подарка) проставляется вручную через `now()->addDays`
- Сравнения срока действия переведены на Carbon/`now()`
- Требует ядро 14.1.0
