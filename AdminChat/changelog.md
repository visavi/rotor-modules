# Changelog

## 1.0.4
- Индекс перед подменой колонок дропается, только если он есть (`1091 Can't DROP`)

## 1.0.3
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- Добавлены смоук-тесты (`Tests/Feature/AdminChatSmokeTest.php`): публикация и правка сообщения, чужое сообщение, очистка только владельцем

## 1.0.2
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.1
- Поля дат сообщений (`chats`: `created_at`/`updated_at`) переведены с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон, пересоздание индекса `created_at`)
- Сравнения/арифметика дат переведены на Carbon/`now()`; включены авто-таймстампы (`$timestamps`), ручные `created_at`/`updated_at` убраны — маркер «изменено» висит на `edit_user_id`, не на `updated_at`
- Маркер новых сообщений (`statsNewChat()` / `users.newchat`) переведён с таймстампа на `id` последнего сообщения — индикатор больше не зависит от формата дат (одноразово: при первом заходе в чат после обновления маркер пересчитается)
- Требует ядро 14.1.0
