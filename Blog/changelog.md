# Changelog

## 1.4.2
- Миграция дат не падает при повторном запуске: временные колонки создаются только при отсутствии (`1060 Duplicate column name`)
- Таблицы создаются только при отсутствии — установка на базу со старого движка не падает (`1050 Table already exists`)

## 1.4.1
- Удаление комментария в списках переведено на ядровой `data-ajax`; заодно блок удалённого комментария наконец пропадает со страницы — раньше вёрстка списка не совпадала с ожиданиями обработчика, и визуально не менялось ничего

## 1.4.0
- og-теги (Open Graph) для статьи: картинка записи и тип `article`
- Точка вставки кнопок «Поделиться» — хук `share`

## 1.3.0
- Счётчик статей в `/api/stats` отдаёт выборку: ядро само считает всего и за сутки, минимальная версия ядра — 14.4.0

## 1.2.0
- API записи: сама статья теперь в `data`, комментарии — в `comments` со своей пагинацией
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- API: создание и правка статьи, черновики и отложенная публикация
- Счётчик опубликованных статей отдаётся в `/api/stats` (ключ `articles`)
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён
- Начисление баллов за статью переживает отсутствующую настройку модуля

## 1.1.0
- Запись отдаёт свою категорию объектом (`category_id` и `category` с родителем), как тема форума отдаёт раздел
- Добавлены список статей `GET /api/articles` (фильтр `category_id`) и категории блогов `GET /api/blogs`
- Добавлен API раздела: `GET /api/articles/{slug}` отдаёт статью с тегами и комментариями постранично, принимает как слаг, так и id; токен необязателен — гость читает, авторизованный получает ещё и свой голос

## 1.0.4
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.3
- `created_at` переведён с int-timestamp на `datetime` (миграция-конверсия через PHP/Carbon, сохраняет исторический DST), добавлено `updated_at`
- Модель на авто-timestamps Eloquent (`$timestamps`), `created_at`/`updated_at` кастуются в Carbon
- Чтения переведены с int на Carbon: RSS `pubDate`, sitemap `lastmod`, статистика «за день», `isNew()`, связи категорий (`new`/`lastArticle`), активация блога
- Требуется ядро 14.1.0

## 1.0.2
- Текст для RSS/API вынесен в метод модели `getShareText()` (`absolutizeUrls(renderHtml())`); rss-шаблон переведён на него

## 1.0.1
- Рейтинг переведён на общий виджет голосования ядра (`app/_rating`)
- Добавлено голосование в списках статей (новые, мои, по тегам) и комментариев (новые, мои)
- Единый стиль кнопок рейтинга и действий (`js-rating`, `js-actions`)
- Обновлён дизайн заголовков и расположения рейтинга/действий в списках статей и комментариев
- Требуется ядро 14.0.1
