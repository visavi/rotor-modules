# Changelog

## 1.1.1
- Удаление записи со стены переведено на ядровой `data-ajax`, свой JS-обработчик больше не нужен
- Ответ на удаление содержит текст сообщения (раньше его подставлял клиент)
- Кнопка жалобы переведена на `data-ajax`

## 1.1.0
- API стены: `GET /api/walls/{login}`, `POST /api/walls/{login}`, `DELETE /api/walls/{login}/{id}`
- Чистить стену может её хозяин, чужие записи удаляет только администрация — как и на сайте
- Счётчик раздела приходит в `/api/stats`
- Импорты переведены с `App\Classes` на `App\Support`
- Требует ядро 14.3.0
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён

## 1.0.3
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.2
- Поле `walls.created_at` переведено с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон, пересоздание индекса `created_at`)
- `$timestamps = false` заменён на `const UPDATED_AT = null` (updated_at-колонки нет, created_at заполняется авто), убран ручной `SITETIME`
- Требует ядро 14.1.0

## 1.0.1
- Кнопки действий (ответить, цитировать, жалоба, удалить) переведены на единый круглый стиль ядра (`js-actions`)
