# Changelog

## Unreleased
- Форма нового блока отвечает 404, а не 500, на массиве `?type[]=`
- Отказы в ajax-запросах (нет записи, нет прав, ничего не выбрано) отвечают кодом 400, 403, 404 или 422 вместо 200 — ошибку видно по статусу
- Форма блока проверяется правилами Laravel, раздельные маршруты на открытие и отправку формы
- HTML-блок из одних тегов (iframe, script виджета) больше не отклоняется как пустой: длина кода считается вместе с тегами
- Создание своего вида записей и включение конструктора главной закрыты на уровне маршрута (`check.admin:boss`)
- Требуется ядро 14.9.0

## 1.0.0
- Первый релиз: своя главная из блоков четырёх типов — текст, записи, HTML-код и шаблон
- Пустую главную можно заполнить готовым набором блоков (портал, новости, сообщество) и сделать главной сайта прямо из конструктора
- Записи: свежие записи одного или нескольких разделов из ленты. Вид — обычный Blade-шаблон: заголовки, заголовки с анонсом и автором, карточки ленты или плитка картинок; кнопка «Изменить вид» копирует вид в `resources/custom/views/home-builder` и открывает копию в редакторе
- В виде у каждой записи одни и те же поля для любого раздела: заголовок, ссылка, дата, анонс, картинка, автор, раздел, комментарии, рейтинг. В форме блока видны поля и их значения у последней записи
- Ошибка в своём шаблоне не роняет главную: блок пропускается, владелец видит ошибку на его месте
- HTML-код выводится без чистки, шаблоны правит только владелец; новый шаблон создаётся из формы блока по имени, сразу с примером внутри. Рамку и заголовок HTML-код и шаблон рисуют сами
- Сетка: блок на всю строку, две трети, половину, треть или четверть, на телефоне — друг под другом
- Показ: всем, только гостям или только пользователям, даты «с — по» в часовом поясе админа; порядок блоков — перетаскиванием, сохраняется сразу; кеш записей сбрасывается новой записью
