# Changelog

## 1.0.0
- Первый релиз
- Обязательная галочка согласия на обработку персональных данных в форме регистрации; в API — поле `privacy`, оно описано в документации API
- Раздел `privacy` в `/api/config`: по нему приложение показывает галочку при регистрации со ссылкой на страницу `/privacy`
- Пометка о согласии под кнопками входа через соцсети (хук `socialAuthNotice` модуля SocialAuth)
- Текст согласия на странице `/privacy` правится владельцем в админке; первая версия собирается из готового шаблона с названием сайта
- Текст, который уже кто-то принял, при правке сохраняется новой версией в таблице `privacy_texts`, прежние версии остаются и открываются в админке. Пока согласий нет, правка меняет текущую версию
- Факт согласия хранится в таблице `privacy_consents`: версия текста, IP и время; удаляется вместе с пользователем
