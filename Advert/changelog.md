# Changelog

## Unreleased
- Кнопки управления модулем в админке выводятся на языке пользователя, а не сайта: в `module.php` ключи перевода вместо `__()`
- Страница настроек показывает боковую панель настроек сайта — переключение между разделами без возврата в админку
- Требуется ядро 14.7.0
- Переключатели в настройках вместо галочек

## 1.0.6
- Пользовательская реклама включается отдельной настройкой `rekuseractive`, раньше выключением служил ноль в «Кол. рекламных ссылок»; при выключении из шапки пропадает и блок ссылок, и предложение разместить рекламу, которое вело в закрытый раздел
- Настройка «Кол. рекламных ссылок» (`rekusershow`) теперь только количество, минимум 1; сайтам с нулём миграция ставит выключенную рекламу и возвращает значение 1
- Сообщение о нехватке баллов берёт число из настройки `rekuserpoint`, раньше в тексте всегда было 50
- Админская реклама сохраняется отдельно для каждого админа, раньше сохранение перетирало запись другого админа
- В админском редактировании ссылки максимальная длина адреса поднята с 50 до 100 символов — как при покупке
- Срок рекламы в правилах склоняется по числу («24 часа», «1 час»), раньше всегда было «часов»
- Адрес и цвет экранируются при сборке html ссылок
- Сборка html пользовательских и админских ссылок объединена в один метод модели
- В списке рекламы в админке иконка перехода на публичный раздел заменена с ключа на глаз

## 1.0.5
- Срок пользовательской рекламы по умолчанию — сутки вместо 12 часов (у работающих сайтов значение в настройках не меняется)
- Срок админской рекламы вынесен в настройку `rekadmintime` (по умолчанию 7 дней), раньше неделя была зашита в коде
- Убрана настройка «Максимум ссылок разрешено» (`rekusertotal`): ссылки выводятся случайной выборкой, ограничивать их число незачем
- Настройки разделены на блоки пользовательской и админской рекламы
- Ссылки на разделы модуля (реклама, админская реклама, настройки) видны на странице модуля в админке

## 1.0.4
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- Добавлены тесты (`Tests/Feature/AdvertTest.php`): покупка рекламы за деньги и баллы, лимит мест, вывод блока хуком, чистка при удалении пользователя

## 1.0.3
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`

## 1.0.2
- Поля `created_at`/`deleted_at` (срок действия рекламы) переведены с int (unix-таймстамп) на `DATETIME` (исторически-корректная конверсия таймзон)
- Включены авто-таймстампы вместо `$timestamps = false`: `const UPDATED_AT = null` (колонки updated_at нет, created_at заполняется авто); `deleted_at` (expiry) проставляется вручную через `now()->addHours/addDays`
- Сравнения срока действия переведены на Carbon/`now()`
- Требует ядро 14.1.0
