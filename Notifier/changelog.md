# Changelog

## Unreleased
- Страница настроек показывает боковую панель настроек сайта — переключение между разделами без возврата в админку
- Требуется ядро 14.7.0

## 1.0.0

- Фоновая проверка новых личных сообщений: счётчик в шапке обновляется без перезагрузки страницы
- Затравка счётчика на странице и ответ опроса берут одно и то же число: расхождение клиент читает
  как новое письмо и отыгрывает звук на каждой загрузке страницы
- Бейдж в шапке выставляется сразу при загрузке, не дожидаясь первого опроса
- Звук уведомления на выбор (`ding`, `chime`, `bell`, `pop`, `soft`, `double`), свой файл можно положить в `resources/assets/sounds`
- Страница настроек: включение, период опроса, звук с прослушиванием, громкость, отметка в заголовке вкладки, уведомления браузера
- Опрашивает сервер только одна вкладка: лидер выбирается через Web Locks, результат расходится по BroadcastChannel
- Запрос счётчика не поднимает пользователя в онлайне и не трогает счётчики хостов и хитов — маршрут исключает `SaveStatistic` и `CheckUserState`
- При ошибках сети интервал опроса растёт экспоненциально, при потере авторизации опрос останавливается во всех вкладках
