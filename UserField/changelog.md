# Changelog

## Unreleased
- Новые типы полей: ссылка, email, телефон, число, дата, список, радиокнопки и переключатель. Тип задаёт поле ввода (клавиатура на телефоне, календарь), проверку значения и вывод в анкете: ссылка открывается с `rel="nofollow"`, телефон — ссылкой `tel:`, дата — в формате дд.мм.гггг, включённый переключатель — «Да»
- У поля появились пример заполнения внутри поля (placeholder) и подсказка под ним
- Список и радиокнопки: варианты задаются в админке по одному на строку, вариантов нужно не меньше двух, принимается только значение из списка. У обязательного списка первым идёт «— выберите —», его нельзя выбрать ответом; необязательные список и радиокнопки очищаются вариантом «— не указано —»
- В форме поля видны только настройки выбранного типа: варианты — у списка и радиокнопок, пример заполнения и мин./макс. — у текстовых полей и числа
- При смене типа поля заполненные пользователями значения удаляются: новому типу они не подходят. Форма заранее предупреждает, у скольких пользователей поле заполнено
- Сохранение профиля через API больше не затирает пользовательские поля и не упирается в обязательные: обрабатываются только поля, пришедшие в запросе. Форма сайта присылает все поля, в том числе выключенный переключатель и невыбранное радио
- Колонка `user_fields.type` переведена из enum в строку: новые типы не требуют изменения схемы

## 1.1.0
- Кнопки управления модулем в админке выводятся на языке пользователя, а не сайта: в `module.php` ключи перевода вместо `__()`, минимальная версия ядра — 14.7.0
- Поля выводятся в анкете тем же списком, что и поля ядра (компонент profile.field)
- Порядок полей задаётся перетаскиванием в списке админки
- Поле «Положение» убрано из формы: новое поле встаёт последним
