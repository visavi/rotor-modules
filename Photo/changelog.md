# Changelog

## 1.0.3
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`
- В `delete()` общий редирект вынесен в переменную — URL одинаков для обеих веток

## 1.0.2
- Поле `created_at` переведено с int (unix-таймстамп) на `DATETIME`, добавлено `updated_at` (миграция с исторически-корректной конверсией таймзон)
- Включены стандартные авто-таймстампы Eloquent (`created_at`/`updated_at` проставляются автоматически)
- Требует ядро 14.1.0

## 1.0.1
- Рейтинг переведён на общий виджет голосования ядра (`app/_rating`)
- Единый стиль кнопок рейтинга в ленте, списке и просмотре фотографий
- Требуется ядро 14.0.1
