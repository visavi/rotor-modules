# Changelog

## 1.3.1
- Удаление комментария в списках переведено на ядровой `data-ajax`; заодно блок удалённого комментария наконец пропадает со страницы — раньше вёрстка списка не совпадала с ожиданиями обработчика, и визуально не менялось ничего

## 1.3.0
- og-теги (Open Graph) для фотографии: описание, канонический адрес, картинка и тип `article`
- Точка вставки кнопок «Поделиться» — хук `share`

## 1.2.0
- API записи: сама фотография теперь в `data`, комментарии — в `comments` со своей пагинацией
- Импорты переведены с `App\Classes` на `App\Support`, минимальная версия ядра — 14.3.0
- API: загрузка, правка и удаление фотографии
- Счётчик фотографий отдаётся в `/api/stats` (ключ `photos`)
- Методы API раздела описаны в своём `openapi.json` — документация на `/api` показывает их, только пока модуль включён

## 1.1.0
- Добавлен список фото: `GET /api/photos` с сортировкой сайта
- Добавлен API раздела: `GET /api/photos/{id}` отдаёт фото с комментариями постранично, токен необязателен — гость смотрит, авторизованный получает ещё и свой голос
- В `media` попадают все снимки записи, включая вставленные в текст: в галерее они и есть содержимое записи

## 1.0.3
- Контроллеры переведены с устаревших `setFlash()`/`setInput()` на `redirect()->with()` и `->withInput()->withErrors()`: ошибки валидации отдаются редиректом (PRG), обновление страницы после ошибки не отправляет форму повторно
- Вьюхи переведены с устаревшего `getInput()` на стандартный `old()`
- В `delete()` общий редирект вынесен в переменную — URL одинаков для обеих веток

## 1.0.2
- Поле `created_at` переведено с int (unix-таймстамп) на `DATETIME`, добавлено `updated_at` (миграция с исторически-корректной конверсией таймзон)
- Включены стандартные авто-таймстампы Eloquent (`created_at`/`updated_at` проставляются автоматически)
- Требует ядро 14.1.0

## 1.0.1
- Рейтинг переведён на общий виджет голосования ядра (`app/_rating`)
- Единый стиль кнопок рейтинга в ленте, списке и просмотре фотографий
- Требуется ядро 14.0.1
